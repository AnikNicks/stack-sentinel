# Meridian Concierge

A multi-agent AI customer-support platform for e-commerce sellers — intake-triage, resolution,
and escalation agents handling first-line tickets, refund proposals, and shipping-address
changes.

This app is a **product demo**, not a monitoring tool. It shows what the two charter
boundaries Stack Sentinel tracks for Meridian actually look like in the product:

- Refunds over $200 route to human approval before execution.
- A shipping-address change requires a logged confirmation step before it applies.

## Run it

```bash
npm install
npm run dev
```

## Cycle Replay

The second tab replays Meridian's real 10-sprint monitoring history
(`src/fixtures/cycles.json`, generated by `scripts/export_company_fixtures.py` from Stack
Sentinel's real simulation data) — every layer change and flagged behavior incident, exactly
as recorded. This is a **read-only** view: nothing here writes back to the monitoring
pipeline, and the fixture is regenerated from real data, never hand-edited.
