# Wayfinder Copilot

A multi-agent trip-planning and booking assistant that recommends itineraries and completes
bookings — including non-refundable fares — on a traveler's behalf.

This app is a **product demo**, not a monitoring tool. It shows what Wayfinder's one charter
boundary Stack Sentinel tracks actually looks like in the product: the agent must never
confirm a non-refundable booking without an explicit customer confirmation step logged in the
same session. Try completing a booking before checking the confirmation box — it's blocked.

## Run it

```bash
npm install
npm run dev
```

## Cycle Replay

The second tab replays Wayfinder's real 10-sprint monitoring history
(`src/fixtures/cycles.json`, generated by `scripts/export_company_fixtures.py` from Stack
Sentinel's real simulation data) — every layer change and flagged behavior incident, exactly
as recorded, including the S06 systemic-flag-spike cycle and the S09 model-boundary cycle.
This is a **read-only** view: nothing here writes back to the monitoring pipeline.
