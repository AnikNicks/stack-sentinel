# Cascade Pipeline Agent

An AI agent managing customer data pipelines — schema-inference, anomaly-detection, and
auto-remediation sub-agents keeping ingestion pipelines healthy.

This app is a **product demo**, not a monitoring tool. It shows the error-budget gauge Stack
Sentinel tracks Cascade against (`monthly_error_budget_consumed_pct`, compliant below 80%,
warning at or above 80%, breach at or above 100%), and the "Recent schema changes" panel,
where a non-reversible migration is shown blocked — pending human approval, never
auto-applied.

## Run it

```bash
npm install
npm run dev
```

## Cycle Replay

The second tab replays Cascade's real 10-sprint monitoring history
(`src/fixtures/cycles.json`, generated by `scripts/export_company_fixtures.py` from Stack
Sentinel's real simulation data), including the real S08 cycle where a `DROP TABLE
raw_events_archive` migration was flagged non-reversible and blocked pending human approval.
This is a **read-only** view: nothing here writes back to the monitoring pipeline.
